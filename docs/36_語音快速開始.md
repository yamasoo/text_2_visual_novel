# 36 語音快速開始（sherpa-onnx）

> 這份是給「只想把小說加上語音」的人看的。  
> 不需要 ComfyUI、不需要顯示卡；CPU 就能跑。  
> **模型檔不會放在 GitHub**，照下面指令下載即可。

## 你需要準備什麼

| 資源 | 做什麼 | 取得方式 |
|---|---|---|
| Windows 10／11 | 目前只在 Windows 實測 | — |
| Python 3.10 以上 | 跑工具與工作台 | [官方下載](https://www.python.org/downloads/windows/)；已安裝就跳過 |
| Git | 取得專案 | [官方下載](https://git-scm.com/download/win) |
| ffmpeg | 把 WAV 轉成 Ren'Py 用的 OGG | [官方下載](https://ffmpeg.org/download.html) |
| sherpa-onnx | 本機 TTS 引擎 | 下面第 2 步 |
| 中文模型 | 實際聲音 | 下面第 3 步，約 116 MB 起 |
| Ren'Py SDK 8.x | 只有要輸出遊戲時需要 | <https://www.renpy.org/latest.html> |

> **不要為了這個專案重裝 Python**，以免影響其他環境。先確認版本：
>
> ```powershell
> python --version
> git --version
> ffmpeg -version
> ```
>
> 有缺再裝；安裝完請關掉再重開 PowerShell，讓 PATH 生效。

## 1. 取得專案並建立環境

```powershell
git clone https://github.com/yamasoo/text_2_visual_novel.git
cd text_2_visual_novel
.\start_studio.bat
```

第一次執行會自動：

- 建立 `venv\`
- 安裝 `requirements.txt`
- 產生 `config.yaml`
- 開啟 <http://127.0.0.1:7866/>

看到工作台後，到 **設定** 頁用「瀏覽…」選作品存放位置與書庫位置，不需要手動改 `config.yaml`。
接著先把這個命令視窗關掉（或按 `Ctrl+C`），補裝語音套件。

## 2. 安裝 sherpa-onnx

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-tts.txt
```

確認：

```powershell
.\venv\Scripts\python.exe -c "import sherpa_onnx; print('sherpa-onnx ok')"
```

## 3. 下載中文模型

模型不進 GitHub，請用專案內的下載工具：

```powershell
# 中文、187 個 speaker，先試這個
.\venv\Scripts\python.exe tools\sherpa_get_model.py vits-zh-hf-fanchen-C

# 可選：音質較好的中文模型（804 個 speaker，較大）
.\venv\Scripts\python.exe tools\sherpa_get_model.py vits-zh-hf-theresa

# 可選：香港粵語
.\venv\Scripts\python.exe tools\sherpa_get_model.py vits-cantonese-hf-xiaomaiiwn
```

下載後應該看到：

```text
models\sherpa\vits-zh-hf-fanchen-C\
  vits-zh-hf-fanchen-C.onnx
  tokens.txt
  lexicon.txt
  phone.fst
  date.fst
  number.fst
```

檢查：

```powershell
Get-ChildItem models\sherpa\vits-zh-hf-fanchen-C
```

`models/` 已列在 `.gitignore`，**不會被推上 GitHub**。

## 4. 設定角色聲線

先匯入一本書，讓 `works\<book_id>\` 出現。下面的 `$book` 改成你的書 id：

```powershell
$book = "my_book"
New-Item -ItemType Directory -Force "works\$book\voice" | Out-Null
Copy-Item config\cast_voice.sherpa.example.json "works\$book\voice\cast_voice.json"
```

打開 `works\<book_id>\voice\cast_voice.json`，先把 `book_id` 改成你的書 id，再確認這兩行：

```json
"book_id": "my_book",
"sherpa_model": "models/sherpa/vits-zh-hf-fanchen-C",
"engine": "sherpa-onnx"
```

每個角色是這樣：

```json
"your_character_id": {
  "source": "speaker_id",
  "speaker_id": 0,
  "speed": 1.0,
  "language": "zh"
}
```

- `speaker_id`：模型裡的編號；不確定就先從 0 開始試
- `speed`：0.5–2.0，1.0 正常
- 角色 id 要跟 `cast.json` 一致；沒設定的角色就不配音

> 想先聽聲音，可以在工作台「語音」頁選模型後，用「試聽」卡輸入文字與 speaker id，按「產生範例語音」。

## 5. 產生語音

### 用工作台

```powershell
.\start_studio.bat
```

開 <http://127.0.0.1:7866/> → 選書 → **語音**：

1. 「模型」選 `vits-zh-hf-fanchen-C` → **套用模型**
2. 「聲線設定」填角色的 speaker id、speed
3. 「章節」填 **從 1 到 5**
4. 按 **生成這個範圍**

### 用命令列

```powershell
.\venv\Scripts\python.exe -m t2vn.voice_gen --book $book --chapters 1-5
```

第一次會載入模型，之後每句約 0.5–5 秒（CPU）。輸出會在：

```text
works\<book_id>\assets\voice\ch001\...
works\<book_id>\voice\VoiceMap.json
```

## 6. 輸出到 Ren'Py

```powershell
.\venv\Scripts\python.exe -m t2vn.export_renpy --book $book --chapters 1-5 --project "C:\你的\RenPy專案"
```

匯出後，Ren'Py 的 `.rpy` 會在對白前插入：

```renpy
voice "audio/voice/ch001/your_character_ch001_sc01_l001.ogg"
```

## 常見問題

| 訊息 | 原因 | 解法 |
|---|---|---|
| `ModuleNotFoundError: No module named 'sherpa_onnx'` | 還沒裝 | `.\venv\Scripts\python.exe -m pip install -r requirements-tts.txt` |
| `model folder not found` | 模型沒下載或路徑錯 | 重跑第 3 步；確認 `models\sherpa\<模型>\*.onnx` 存在 |
| `ffmpeg not found` | ffmpeg 不在 PATH | 到 <https://ffmpeg.org/download.html> 下載，確認 `ffmpeg -version` 可用 |
| `speaker_id ... 超出模型 ... 範圍` | ID 超過該模型的 speaker 數 | 換小一點的 ID；fanchen-C 是 0–186 |
| 出現 `Ignore OOV` | 模型字典沒有該字 | 已預設過濾；該字可能不會發音，必要時改字或補 `lexicon.txt` |
| 匯出後沒聲音 | `VoiceMap.json` 沒生成，或匯出沒帶 `--no-voice` | 先確認 `works\<book_id>\voice\VoiceMap.json` 有資料，再重新匯出 |
