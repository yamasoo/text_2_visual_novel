# 標註規則 v0.1（S2 黃金集與 S4 管線共用）

> 機器版（給 LLM 的提示詞）是 `prompts/annotate_system.md`，兩份要同步修改。
>
> 把正規化後的章節（`chapters/chNNN.json`）轉成 scene graph（`scenes/chNNN.json`）時的人工／AI 共用規則。格式以 `docs/05_資料格式規格.md` 與 `schema/scene.schema.json` 為準；本檔只規定「怎麼判斷」。S2 黃金集完成後，這份規則會做成 `vn-annotate` 技能。

## 1. 分場

- 換場的訊號（依強弱）：地點改變 → 時間跳躍（「將近中午的時候」）→ 焦點對象改變（換下一艘船、換下一個人）→ 視角大幅收窄（鑽進囊裡的特寫）。
- 一場通常 8–25 段；少於 4 段的不單獨成場，除非是本章結尾的關鍵畫面。
- 參考章綱的「情節點」：一個情節點通常是一場，兩個緊連、同地點同角色的情節點可以合併。
- 分場邊界以**段落**為單位，不在段落中間切。

## 2. 台詞與旁白

| 原文 | 怎麼轉 |
|---|---|
| 引號 `「」` 內的話 | `dialogue`，去掉引號 |
| 同一段被動作分開的兩截話（`「好了，」她拍拍工具箱，朝老張喊，「試一趟看看。」`） | 兩截合成一句 `dialogue`；中間的動作若有內容，另成一句 `narration` 放在台詞**前面** |
| 純說話標記（`她說。`、`老張問。`） | 刪掉，VN 會顯示說話者名字。只限「某某＋說／問／道／答」；帶動作、語氣或否定的（`艾莉打斷他`、`聲音壓得很平`、`老漁民沒有馬上回答`、`最後只說了一句`）是敘述，要保留。`annotate.omitted_clauses` 會檢查，漏掉的視為問題 |
| 帶情緒或動作的說話標記（`聲音壓得很平`） | 用 `expr` 表達；有畫面價值的動作才另留 `narration` |
| 敘述 | `narration`，**保留原文**，只在句末（。！？）斷句；一句超過 90 字才在逗號斷 |
| 角色心裡的話，原文有「她想」等標記 | `dialogue`，`speaker` 用 `player`（只限主角內心獨白） |
| 自由間接引語（沒有「她想」，用敘述口吻寫的想法） | 保留為 `narration`，不轉成 `player` |
| 被打斷的話（`「可是——」`） | 保留破折號 |

- 每一行的 `source_para` 是它來自的段落編號；一段拆成多行時沿用同一個編號。
- 黃金集**不改寫、不刪減敘述**（除了上表的說話標記），這樣才能逐段比對覆蓋率；縮寫旁白是 S4 之後的改編選項，不是標註。

## 3. 說話者

- `speaker` 必須是 `cast.json` 裡的 `char_id`，或 `player`。
- 判斷依據順序：同段的說話標記 → 上下句的稱呼（「艾莉姐」「阿弟」）→ 對話輪替（兩人對話時交替）→ 語氣與內容。
- 輪替推斷的行在校對表標 `?`，給校對者優先看。
- 只被提到、沒有說話的人（老何）不放進該場的 `cast`。

## 4. 表情 `expr`

八個值：`neutral`、`smile`、`sad`、`angry`、`surprised`、`worried`、`serious`、`embarrassed`。

| 原文線索 | expr |
|---|---|
| 平常交代、指示、陳述 | `neutral` |
| 專注、壓著情緒、聲音「很平」、下定決心 | `serious` |
| 不安、遲疑、聲音變小、搓手、喉結動 | `worried` |
| 質疑、提高音量、甩手、頂嘴 | `angry` |
| 嚇一跳、沒想到 | `surprised` |
| 難過、洩氣 | `sad` |
| 尷尬、打圓場時陪笑 | `embarrassed` |
| 開心、調侃 | `smile` |

- 原文沒有線索時沿用該角色在本場的上一個 `expr`；本場第一句沒有線索用 `neutral`。
- `cast[].expr` 是角色**出場時**的表情。
- 拿不準時選比較「平」的那個（`serious` 優於 `angry`、`worried` 優於 `sad`），避免立繪表情過度。

## 5. 演出欄位

- `location_id`、`bg.asset_id`、`bgm`、`ambience`：先用描述性英文 ID（`scrapyard`、`bg_scrapyard_dawn`），素材階段再對到 manifest。同一地點同一時段共用一張背景。
- `time_of_day`：原文有明說才填明說的時段；沒說就沿用前一場。
- `weather`：原文沒寫就**不填**（選填欄位），不要猜。
- `direction`：只在原文有明確的突發動作（震動、撞擊、閃光）時加 `shake`／`flash`。
- `pos`：主角 `left`、主要對手 `right`、第三人 `center`；只有一人時 `center`。

## 6. 角色 ID

- 手動取，用羅馬拼音或英文描述，不從中文自動產生：`lao_zhang`（老張）、`chen_boatman`（陳姓船主）。
- 沒有名字的角色用「身分＋區別」：`harbor_skipper`（港邊的船主）。
- 新角色先加進 `cast.json`（含 `names.zh-TW` 與 `aliases`），再標註。
