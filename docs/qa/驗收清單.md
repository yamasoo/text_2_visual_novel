# 視覺小說驗收清單（vertical slice：《示範小說》第 1–5 章）

> 給**獨立驗收者**（另開的 Claude 對話，建議 Opus）與試玩的人共用。
> 原則：**只驗收、不修改**；每個結論都要有證據（檔名＋行號／章節＋段落號／截圖名稱）；沒驗到的項目寫「未驗證」，不要寫「通過」。

## 0. 先搞清楚手上有什麼

- [ ] 讀 `PACK.md`：章節範圍、缺少的檔案、檔案清單。
- [ ] 讀 `CLAUDE.md`、`docs/05_資料格式規格.md`、`docs/30_RenPy匯出規格.md`（資料格式與匯出約定）。
- [ ] 確認「原文」是 `source/chNNN.json`（含段落編號 `source_para`），「劇本」是 `scenes/chNNN.json`，「成品」是 `renpy/game/*.rpy`＋打包的 zip。
- [ ] 自動驗收報告（`verify_report/`）只是**聲稱**，不是證據；下面 B 區要自己複核。

## A. 範圍與已知限制（不算缺陷，但要確認真的是這樣）

- 只有 zh-TW、第 1–5 章；沒有選項分支（`choice` 不支援）、沒有語音。
- 立繪與頭像依角色等級出圖：主角各表情都有立繪與頭像；主要角色只有 neutral 立繪、頭像各表情；其他角色各一張 neutral。缺的表情圖退回 neutral。
- 自動驗收拍不到結局的「完」畫面（快轉太快），**必須人工看**（C 區）。

## B. 自動驗收複核

- [ ] `verify_report/report.md` 五項（啟動、畫面、輸入、主循環與結局、重開）都是「通過」；若不是，記錄原因。
- [ ] `verify_report/lint.txt`：沒有錯誤；警告逐條說明是否可接受。
- [ ] `verify_report/screens/`：每張截圖都看過。檢查：標題畫面（標題圖＋選單）、場景畫面（背景、立繪、對話框、說話者名稱）、**立繪頭部沒被裁掉**、**同場多人沒有重疊**、字型是中文字（不是方框）。
- [ ] `renpy/media_inventory.tsv` 與 `.rpy` 引用的 `images/…`、`audio/…` 路徑對得上（有引用沒有檔案＝缺圖／缺音）。

## C. 試玩（人工；驗收者指示、試玩者操作並回報，或驗收者自己有桌面操作能力）

用**打包出來的 zip** 解壓後的遊戲，不要用開發資料夾裡的專案。

### C1. 標題與開始
- [ ] 標題畫面有背景圖與標題音樂；按鈕（開始遊戲、讀取、設定…）都能點。
- [ ] 「開始遊戲」進入第 1 章，出現章節標題卡「第 1 章　補囊」。

### C2. 逐章閱讀（每章至少走完整章，不可只抽樣開頭）
- [ ] 對白一句一句出現，沒有一次出現過長（超出對話框）或被截斷的句子。
- [ ] 說話者名稱正確、名稱顏色穩定；旁白沒有說話者名稱。
- [ ] 角色頭像（對話框旁）會隨表情改變；缺表情時不會出現破圖。
- [ ] 立繪位置合理、不互相遮住、頭部完整；角色離場／換場後沒有殘影。
- [ ] 場景切換時背景、地點・時段字幕正確；音樂／環境音在換場時切換自然（有淡入淡出，沒有突然靜音或疊音）。
- [ ] 章節之間自然銜接（第 1→2→3→4→5 章），沒有跳回標題、沒有卡住。

### C3. 結局
- [ ] 第 5 章結束後出現「完」，再回到標題畫面。**（自動驗收看不到這格，必看）**

### C4. 玩家功能
- [ ] 快轉（Ctrl／Tab）能快速前進、到點能停；已讀快轉不會跳過未讀。
- [ ] 回溯（滾輪上／方向鍵）能退回上一句。
- [ ] 歷史紀錄（H）內容與說話者正確。
- [ ] 手動存檔、讀檔（含章節中間）成功；讀檔後畫面（背景、立繪、音樂）與存檔時一致；自動存檔存在。
- [ ] 設定（音量、文字速度、全螢幕／視窗）可用；調音量立即生效。
- [ ] 從遊戲中回主選單、再開始新遊戲，狀態乾淨（沒有上一輪殘留的立繪或音樂）。

## D. 內容忠實度（抽樣；樣本數寫進報告）

- [ ] **逐字**：每章隨機抽至少 10 行（對白＋旁白各半），用 `source_para` 對回 `source/chNNN.json` 的原文，確認文字與原文一致（允許的差異只有半形／全形標點，且報告要記錄）。
- [ ] **說話者**：每章至少 20 句對白，確認說話者是原文中真正開口的人；特別看連續對話、省略主詞、第三人稱轉述。
- [ ] **旁白不含引號台詞**：整段旁白裡不應夾著應由角色念的話。
- [ ] **名詞一致**：人名、地名、組織名、專有名詞前後一致，沒有簡繁混用、沒有誤字（原文本身的錯字若被照抄，記為「原文問題」，不算管線缺陷）。
- [ ] **表情合理**：抽 15 個表情標註，是否符合該句語氣。
- [ ] **覆蓋率**：每章 `source_para` 是否涵蓋原文段落（沒有整段漏掉）；有刻意省略的要能找到理由。
- [ ] **場景切分**：場景邊界（地點／時間改變處）是否合理；沒有一個場景橫跨兩個明顯不同的地點。

## E. 資料與程式契約

- [ ] `scenes/chNNN.json` 符合 `schema/` 的 schema（用任一 JSON Schema 工具驗）。
- [ ] 所有 `speaker`、`char_id`、`location_id`、素材 id 只含 `[a-z0-9_]`，且都存在於 `cast.json`／素材清單。
- [ ] 讀 `renpy/game/vn_ch*.rpy`、`script.rpy`、`vn_end.rpy`：每個 label 的 `jump` 目標存在；`start` 能走到 `vn_end`；沒有死路。
- [ ] `vn_export.json` 與 `.rpy` 的章節／素材一致。
- [ ] 劇本裡沒有 `choice`（v1 不支援）。

## F. 打包與換機

- [ ] zip 內有 `.exe`，且**沒有**：`game/saves/`、`vn_verify_test*`、`_tracesave*`、`traceback.txt`、`errors.txt`、`tests/`（Ren'Py 自己放的 `game/cache/build_info.json`、`bytecode-*.rpyb` 是正常的，不算；執行後才出現的 `py3analysis.rpyb`、`screens.rpyb` 也不算）。
- [ ] 解壓到**沒裝 Ren'Py** 的另一台 Windows（或乾淨使用者帳號），直接執行能啟動、能玩到結局。
- [ ] 解壓路徑含中文與空格時仍能啟動。
- [ ] 第一次啟動沒有跳出錯誤對話框；`log.txt`／`errors.txt`（若產生）沒有 Exception。
- [ ] 檔案大小合理（記錄實際大小）；視窗縮放與全螢幕切換正常。

## G. 判定

嚴重度：

| 等級 | 定義 | 範例 |
|---|---|---|
| **阻擋** | 無法完成基本流程或資料錯誤會誤導讀者 | 啟動失敗、卡死、結局到不了、說話者大量錯、zip 缺 exe |
| **重要** | 能玩但明顯影響品質 | 立繪被裁、人物重疊、缺圖、缺音、單章有 1 句以上漏譯／漏段 |
| **次要** | 小瑕疵 | 單一表情不貼切、字幕時段文字不順 |
| **建議** | 非缺陷的改進 | 想法、風格 |

- **通過**：阻擋 0 且重要 0。
- **有條件通過**：阻擋 0，重要 ≥ 1 但都有明確修法；列出必修清單。
- **不通過**：任何阻擋。
