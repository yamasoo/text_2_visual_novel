# 31 美術管線規格（S6）

> 版本：v0.1（2026-11-01）　狀態：**草案**。輸入：`scenes/`／`gold/`、`cast.json`、`prototype/style.json`。輸出：`works/<book>/assets/{bg,sprite}/*.png`，格式見 `docs/05` §5.5（`manifest.json`）。
> 出圖後端：ComfyUI（沿用 `vendor/novel_studio/comfy.py`：workflow 分析、LoRA 注入、送出、輪詢、取圖，只用標準庫）。模型：Anima（Danbooru 標籤＋英文句子）。

## 1. 流程

```
scenes/gold ─▶ [asset_manifest] ─▶ manifest.json（planned）
                                     │
art/style.json（畫風、地點、角色描述）─┤
                                     ▼
                              [art_prompts] ─▶ 正向／負向提示詞＋尺寸＋種子
                                     ▼
                              [art_gen] ─ ComfyUI ─▶ assets/_candidates/<asset_id>/<seed>.png（＋同名 .json）  manifest: generated
                                     ▼  使用者在「素材」頁挑一張
                              選定 ─▶ bg：縮放成 1920×1080 → assets/bg/<id>.png
                                      sprite：[sprite_cutout] → assets/sprite/<char>_<expr>.png     manifest: selected → processed
                                     ▼
                       匯出器（S5）自動取代佔位圖；授權填好後狀態可標 final
```

## 2. 決定

| # | 決定 | 理由 |
|---|---|---|
| A1 | 只做背景與立繪；CG、封面、UI 不在 v1。 | 先讓遊戲有基本畫面 |
| A2 | 不會因為重掃而掉進度：`manifest.json` 以 asset_id 合併，已有的狀態、提示詞、種子、授權保留；不再使用的項目留著、`used_in` 清空。 | 避免重跑浪費出圖時間 |
| A3 | 立繪用白底生成，再用 `sprite_cutout` 去背（只去與邊緣相連的單色區域）。 | 不依賴額外模型或自訂節點 |
| A4 | 每個素材出多張候選（預設 4），存在 `assets/_candidates/`；人挑一張才進 `assets/bg|sprite/`。 | 圖不一定一次出好 |
| A5 | 種子固定（`seed_for(asset_id, attempt)`）；重出圖用 attempt+1。 | 可重現 |
| A6 | 畫風設定放 `works/<book>/art/style.json`，程式內只有保底預設；地點與角色的外觀描述由使用者（或 AI 草擬後使用者確認）填寫。 | 外觀是創作決定，不可由程式猜 |
| A7 | 授權欄位必填才能標 `final`（schema 已規定）；AI 生成的圖由使用者自行確認授權。 | docs/05 §5.5 |
| A8 | 出圖工具不自動重試超過 2 次；失敗的項目標記原因，其餘繼續（可從失敗處續跑）。 | 沿用標註的做法 |

## 3. 模組與分工

| 模組 | 內容 | 誰 |
|---|---|---|
| `t2vn/asset_manifest.py` | 場景 → 素材清單、合併進度 | DS（卡 `t_s6_asset_manifest`） |
| `t2vn/art_prompts.py` | 素材＋畫風 → 提示詞／尺寸／種子 | DS（卡 `t_s6_art_prompts`） |
| `t2vn/sprite_cutout.py` | 白底立繪 → 透明、裁切、定位 | DS（卡 `t_s6_sprite_cutout`） |
| `t2vn/art_gen.py` | 依 manifest 逐項呼叫 ComfyUI、存候選、更新狀態、可續跑、可停止 | Claude |
| `t2vn/server.py`＋`ui/page_assets.js` | 「素材」頁：清單、畫風設定、出圖、挑圖、狀態 | Claude |

## 4. `works/<book>/art/style.json`

形狀同 `art_prompts.DEFAULT_ART`（`quality safety artist extra negative bg sprite locations characters`）；另外有出圖設定：

```json
{"comfy": {"profile": "anima", "workflow": "", "unet": "", "clip": "", "vae": "", "loras": [], "steps": null, "candidates": 4}}
```

`workflow` 空白＝用 novel-studio `examples/comfy/anima.api.json` 範本（需複製進本專案 `works/<book>/art/` 或 `config/comfy/`）。

## 5. 驗證

- 自動：三個純函式模組的測試；`art_gen` 用假的 ComfyUI 客戶端測流程（續跑、停止、失敗隔離、狀態轉換）。
- 使用者：開 ComfyUI → 「素材」頁對一張背景、一個立繪出圖 → 挑圖 → 重新匯出 → 在 Ren'Py 看到真圖取代佔位圖。

## 6. 已知限制（v1）

- 立繪只有站姿全身；沒有差分（表情只靠提示詞改變，同一角色臉可能略有不同）。
- 去背只處理單色背景；頭髮細節邊緣可能殘留白邊（可調 tolerance）。
- 不做放大模型；背景 1344×768 直接縮放到 1920×1080。
