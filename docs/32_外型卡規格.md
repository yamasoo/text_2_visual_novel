# 32 外型卡與 wildcard 規格（S6）

> 版本：v0.2（2026-11-02）　狀態：草案，使用者已確認（見 HANDOFF 0.15）。補充 `docs/31`。v0.1 的「頭像六欄＋立繪兩欄」已取代為**兩個提示詞框**。

## 1. 流程

```
角色卡（設定集）＋小說內文證據
   └─ [appearance_draft] AI 草擬 ─▶ 兩個提示詞：頭像（頸部以上）、立繪（衣服／身體／動作）
        └─ 使用者修改（可用 wildcard 自動補全、按「擲骰」把 __名稱__ 固定成具體文字）、勾選頭像表情 ─▶ 勾「確認」
             └─ 出圖（各角色卡自己的按鈕：頭像／立繪／張數）─▶ 素材清單的 headshot_*／sprite_* 項目 ─▶ 在素材清單挑圖
                  └─ 立繪：去背；頭像：不去背
```

## 2. 外型卡

位置：`works/<book>/art/appearance/<char_id>.json`（一角色一檔）；格式見 `schema/appearance_card.schema.json`。

```json
{"char_id": "ellie_reed", "confirmed": false,
 "headshot_prompt": "black hair, long hair, straight bangs, brown eyes, hair ornament, earrings",
 "sprite_prompt": "work apron, grey shirt, wrench in pocket, standing, arms crossed",
 "expressions": ["neutral"], "notes": ""}
```

- 兩個提示詞都是字串：Danbooru 標籤（逗號分隔）、短英文片語，或含 `__名稱__` 的 wildcard 引用，可混用。
- **頭像提示詞**：頸部以上的視覺描述——髮型、髮色、眼型、眼色、頭飾、耳環、項鍊、特殊特徵（美人痣）。**不含表情**（表情由 `expressions` 勾選帶入預設提示詞）。
- **立繪提示詞**：衣服、身體、動作（依勢力或職業的制服）。
- 出圖時：**頭像提示詞＝頭像提示詞＋表情預設**；**立繪提示詞＝頭像提示詞＋立繪提示詞＋場景表情預設**（立繪的臉才會和頭像一致）。存檔時把這兩組同步到 `art/style.json` 的 `characters.<id>.headshot_tags`（頭像）與 `characters.<id>.tags`（立繪＝兩框合併）。
- `expressions`：要出的頭像表情，預設 `["neutral"]`；選項與預設提示詞：平靜 neutral＝`neutral expression, closed mouth`、喜 smile＝`smile, happy`、怒 angry＝`angry, furrowed brow`、哀 sad＝`sad, downcast eyes`、樂 laughing＝`laughing, open mouth, happy`。每勾一個表情，素材清單多一個 `headshot_<char_id>_<expr>` 項目（出圖預設每項一張）。
- `confirmed`：使用者確認過才算；沒確認仍可出圖，任務紀錄提醒。

## 3. 出圖尺寸（比例決定構圖）

模型的構圖由畫布長寬比決定，提示詞的 `full body` 擋不住半身。規則：**頭像 3:4（可改 1:1）、立繪窄長（9:21）、背景 16:9**；寬高為 16 的倍數、總像素約 1 MP。預設值在 `art_prompts.DEFAULT_ART`：背景 1280×720、立繪 672×1568、頭像 864×1152；可在 `art/style.json` 的 `bg`／`sprite`／`headshot` 覆蓋。

## 4. Wildcard

- 位置：`vendor/wildcards/*.txt`（使用者的共用庫，唯讀，不含子資料夾）。
- 引用語法：`__名稱__`，名稱只含 `[a-z0-9_]`。名稱＝檔名（不含 .txt）轉小寫、非英數連續字元換成單一底線；開頭不是字母加 `w_`；衝突時依檔名不分大小寫排序，留第一個並警告。**不改使用者的檔名。**
- 檔案格式：一行一個選項；空行與 `#` 開頭略過；行尾逗號去掉；重複選項只留第一個；UTF-8（可含 BOM）、CRLF 或 LF。一行可以是整句描述，整行就是一個選項，不拆。`(標籤:1.3)` 權重寫法原樣保留。
- 展開：同樣的輸入與種子永遠得到同樣結果（sha256）；巢狀引用最多 5 層；未知名稱原樣保留並警告。
- 擲骰：展開後的具體文字寫回提示詞框；之後出圖不再隨機，同一角色的臉才會穩定。**出圖前還留著 `__名稱__` 的部分會被丟掉**（不會原樣送給模型）。
- **自動補全（a1111 風格）**：在提示詞框輸入 `__` 加幾個字母，彈出名稱以這些字母開頭的 wildcard（只列啟用的）；↑↓選擇、Tab 或 Enter 補成完整的 `__名稱__`；Esc 關閉。預設全部啟用，啟用清單只當篩選。
